# Runtime dependencies for the hosted demo (Render) and local runs. Render's
# native Python build auto-detects this file and runs `pip install -r
# requirements.txt`, so it needs the web extra (fastapi + uvicorn); the Docker
# build installs the same via pyproject. `streamlit` is here for the optional
# local `streamlit run app.py` UI (it isn't a package dependency).
#
# Installing the package itself with `-e .[web]` is what ties this together: it
# pulls every runtime dep from pyproject (chromadb, cohere, anthropic, langgraph,
# ...) AND the web extra, AND makes both `rag_revops` (under src/) and the
# top-level `web` package importable — which `uvicorn web.server:app` requires.
# The explicit pins below are redundant with the editable install but kept as a
# belt-and-suspenders lockstep with pyproject; dev/eval extras are omitted.

# The package + its web service (fastapi, uvicorn) + all runtime deps.
